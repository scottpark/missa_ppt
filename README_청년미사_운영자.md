# 청년미사 PPT 자동 생성 프로그램 — 운영자 안내서

## 이 프로그램이 하는 일

그날의 영어 복음·독서 등을 자동으로 가져오고, 성당 공용 OneDrive('PPT 문서' 폴더)의
성가/공지사항/시작기도/미사 후 기도 파일을 이용해 청년미사 PPT를 자동으로 만들어 줍니다.

## 최초 1회 준비 (컴퓨터당 한 번만)

1. **Python 설치**
   - [python.org/downloads](https://www.python.org/downloads/)에서 최신 버전을 내려받아
     설치합니다.
   - 설치 화면 맨 아래에 있는 **"Add python.exe to PATH"** 체크박스를 반드시 체크한 뒤
     설치를 진행합니다(이걸 빠뜨리면 나중에 실행이 안 됩니다).
2. **프로그램 폴더 압축 풀기**: 전달받은 `missa_ppt` 폴더(zip)를 원하는 위치에 압축을
   풉니다.
3. **필요 패키지 설치**: 그 폴더 안의 **`install.bat`**을 더블클릭합니다. 검은 창이
   뜨면서 필요한 프로그램들을 자동으로 설치합니다 — "설치가 완료되었습니다" 문구가
   뜨면 창을 닫아도 됩니다.

여기까지가 최초 1회만 하면 되는 준비 과정입니다.

## 매번 실행하는 방법

1. `missa_ppt` 폴더 안(또는 바탕화면)의 **"청년미사 PPT" 바로가기**를 더블클릭합니다.
   (바로가기가 없다면 폴더 안 `missa_to_ppt.py`를 개발 담당자가 안내한 방식대로
   실행합니다.)
2. **최초 실행 시에만** "'PPT 문서' 폴더를 선택해 주세요" 창이 뜹니다. 이 컴퓨터에서
   동기화 중인 OneDrive의 **'PPT 문서'(성당 PPT 문서) 폴더 하나**를 선택하세요. 한 번
   선택하면 저장되어 다시 묻지 않습니다. 성가·결과 저장 위치(`09.가톨릭 성가`,
   `20.청년 미사` 등)는 프로그램이 이 폴더 아래에서 알아서 찾습니다.
   - 선택한 폴더 안에 `20.청년 미사` 폴더가 있어야 합니다(없으면 다시 선택하라는
     안내가 뜹니다). 저장된 폴더가 나중에 사라지거나 이동되거나 `20.청년 미사`가 없어지면
     다시 선택창이 뜹니다.
   - **폴더를 선택하지 않고 취소하면** 이번 실행은 Microsoft 계정 로그인 방식으로
     진행됩니다(부록 C 참고). 이 경우 다음 실행 때 폴더 선택창이 다시 뜹니다.
3. 날짜를 선택하고, 일반 파일 선택창으로 이번 주 참조 PPT·시작기도·미사 후 기도·
   공지사항 파일을 골라 확인을 누릅니다. '찾아보기'는 파일 종류에 맞는 폴더에서 바로
   시작합니다(시작기도·미사 후 기도 → `13.기도문`, 공지사항 → `11.공지사항 PPT문서`,
   참조 미사 PPT → `20.청년 미사\1.Template`).
4. 자동으로 PPT가 만들어집니다. 처음 5초 동안 진행 창 맨 위에 "PowerPoint가 백그라운드에서
   실행됩니다" 안내가 함께 보입니다.
5. 완성된 PPT는 **프로그램 폴더의 `output`에만 만들어집니다.** 내용을 확인한 뒤, 결과 창의
   **'원드라이브로 복사'** 버튼을 눌러 OneDrive에 올립니다(아래 '결과 파일 위치' 참고).

## 결과 파일 위치

- 프로그램 폴더의 `output\{날짜}_youth\` 안에 저장됩니다.
- 프로그램이 OneDrive에 자동으로 복사·업로드하지는 않습니다. 결과를 확인한 뒤 결과 창에서
  **[원드라이브로 복사]**(파일 열기 바로 옆 버튼)를 누르면 'PPT 문서'
  폴더 아래 `20.청년 미사\{연도(YYYY)}\`에 저장되고(연도 폴더가 없으면 자동으로 만듭니다),
  저장된 폴더를 안내해 줍니다. 같은 이름의 파일이 이미 있으면 덮어쓸지 먼저 묻습니다.
  OneDrive 앱이 알아서 동기화합니다.
- (로그인 방식으로 진행한 경우) 같은 버튼이 같은 위치(`PPT 문서/20.청년 미사/{연도}`)에 OneDrive로
  직접 업로드합니다.
- 버튼을 쓰지 않고 `output` 폴더의 파일을 직접 올려도 됩니다.

## 문제가 생기면

화면의 오류 메시지를 캡처해서 개발 담당자에게 전달해 주세요. 아래 부록에 설치·실행
관련 자세한 내용과 흔한 문제를 정리해 두었습니다.

# 부록 (Appendix)

## A. Python 설치 확인 방법

설치가 제대로 됐는지 확인하려면, 시작 메뉴에서 **"명령 프롬프트"**(또는 PowerShell)를
열고 아래처럼 입력해 봅니다.

```
python --version
```

`Python 3.x.x` 같은 버전이 나오면 정상입니다. `'python'은(는) 내부 또는 외부 명령...`
같은 오류가 나오면 설치 시 "Add python.exe to PATH" 체크를 빠뜨린 것이니, Python을
다시 설치하면서 그 항목을 꼭 체크합니다.

## B. `install.bat`을 실행했는데 오류가 난다면

- "패키지 설치에 실패했습니다"가 뜨면 대부분 Python/PATH 설정 문제입니다 — 부록 A를
  먼저 확인합니다.
- 그래도 안 되면 검은 창에 나온 오류 메시지 전체를 캡처해 개발 담당자에게 전달합니다.

## C. OneDrive 로그인 관련 (폴더를 선택하지 않았을 때만 해당)

기본 방식은 'PPT 문서' 폴더를 직접 선택하는 것이라 **로그인이 필요 없습니다**. 아래는
폴더 선택창에서 취소했거나, 이 컴퓨터에 OneDrive 동기화 폴더가 없어 로그인 방식으로
진행하는 경우의 안내입니다.

- 이 컴퓨터에 'PPT 문서' 폴더가 동기화되어 있지 않다면, OneDrive 앱에서 성당 공용
  폴더를 먼저 동기화한 뒤 프로그램을 다시 실행해 폴더를 선택하는 것을 권장합니다
  (로그인 방식은 파일 하나를 가져올 때마다 인터넷 조회가 필요해 훨씬 느립니다).
- 설정한 폴더를 바꾸고 싶으면 프로그램 폴더의 `config.json`에서 `onedrive_ppt_folder`
  항목을 삭제한 뒤 다시 실행하면 선택창이 다시 뜹니다.
- 로그인은 **컴퓨터/사용자 계정당 최초 1회**만 필요합니다. 같은 컴퓨터에서 다시 실행할
  땐 로그인 화면이 다시 뜨지 않아야 정상입니다.
- **로그인 링크는 반드시 새 시크릿 창(크롬: `Ctrl+Shift+N` 새 시크릿 창 / 엣지:
  `Ctrl+Shift+N` InPrivate 창)에서 여세요.** 평소 쓰던(시크릿이 아닌) 창에서 열면, 그 브라우저에
  이미 로그인돼 있는 **다른 개인 Microsoft 계정으로 자동으로 로그인이 진행**될 수
  있습니다 — 성당 공용 계정 입력창이 아예 안 뜨고 엉뚱한 계정으로 넘어가 버리는
  것입니다. 시크릿 창은 기존 로그인 정보를 전혀 쓰지 않으므로, 이 문제 없이 항상
  성당 공용 계정을 직접 입력할 수 있습니다.
  - 만약 시크릿 창이 아닌 곳에서 열었는데 다른 계정으로 자동으로 넘어갔다면, 로그인
    화면에서 **"다른 계정 사용"**을 눌러 성당 공용 계정을 다시 입력하면 됩니다.
- 공용 계정 비밀번호는 개발 담당자 또는 담당 사목회에 문의합니다.
- 로그인 방식에서는 인터넷이 안 되는 환경에서 OneDrive 파일 목록을 불러올 수 없어
  프로그램을 쓸 수 없습니다(폴더 선택 방식은 동기화된 파일만 있으면 인터넷 없이도
  동작합니다).

## D. 실행 중 PowerPoint 관련 안내

프로그램이 줄 수를 정확히 맞추기 위해 PowerPoint를 화면에 보이지 않게(백그라운드로)
잠깐 실행합니다(처리가 시작되면 진행 창 맨 위에 5초 동안 이 안내가 표시됩니다). 작업표시줄에 PowerPoint 아이콘이 잠깐 나타날 수 있는데, 화면에
창이 뜨거나 지금 하던 작업의 포커스를 빼앗지는 않으니 그대로 두시면 됩니다.

## E. 버전 확인

입력 화면 하단에 `20260926-01` 같은 형식의 버전 번호가 표시됩니다. 옆의 링크를
누르면 최신 버전이 있는지 확인할 수 있습니다. 문의 시 이 번호를 함께 알려주세요.

## F. 다시 설치해야 할 때

프로그램 폴더 전체를 삭제하고 새 폴더를 받아 최초 1회 준비 과정(Python 설치는
한 번 해뒀다면 건너뛰고, `install.bat`부터)만 다시 하면 됩니다.
