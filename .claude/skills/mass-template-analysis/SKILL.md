# Mass Template Analysis

새 참조 PPT를 "추측"이 아니라 "실측"으로 조사하는 절차. missa_ppt 프로젝트에서 반복적으로
확인된 원칙 — 문서나 기억이 아니라 실제 파일을 열어 확인해야 한다 — 을 새 템플릿 조사에도
그대로 적용한다.

## 언제 이 스킬을 쓰는가

- 사용자가 새 미사 유형(청년미사/어린이미사)이나 새 성당의 참조 PPT를 제공했을 때
- 기존 템플릿과 구조가 얼마나 다른지 파악해야 할 때
- `find_sections()`가 새 템플릿에서도 올바른 슬라이드를 찾는지 검증할 때

## 절차

### 1. 슬라이드 인벤토리 덤프

```
python .claude/skills/mass-template-analysis/scripts/dump_slide_text.py "<참조PPT경로>" --max-chars 60
```

출력은 `슬라이드번호 \t 텍스트조각들`. 이 목록을 근거로 아래 섹션들이 몇 번 슬라이드에
있는지 표로 정리한다: 제목, (미사 전 준비 슬라이드가 있다면 그 범위), 입당송, 제1독서 제목/본문,
화답송, 제2독서, 복음환호송, 복음 제목/본문, 신경(있다면), 봉헌, 성찬 전례 통상문(거룩하시다·
주님의 기도·하느님의 어린양 등, 있다면), 영성체송, 성체 성가, 2차봉헌(있다면), 공지사항(있다면),
파견.

**성인미사에 없던 섹션이 나오면 놓치지 말고 목록에 추가한다** — 예: 청년미사의 이중언어 표기,
공지사항 슬라이드, 묵주기도 슬라이드, 미사통상문 음악 설정(작곡가 표기)은 성인미사 참조 PPT에는
없는 섹션이었다. "성인미사에 있던 것만 확인하고 끝내는" 방식은 새 섹션을 놓친다.

### 2. 기존 `find_sections()`와 대조

`missa_to_ppt.py`의 `find_sections()`(전체 함수 목록은 `docs/ARCHITECTURE.md` §4
참고)가 어떤 텍스트 패턴으로 각 섹션을 탐지하는지 읽는다. 새 템플릿의 실제 슬라이드 텍스트가
그 패턴과 일치하는지 한 줄씩 확인한다. 예: 복음 제목 슬라이드는 shape 텍스트가 "복 음" 단독으로
있는 슬라이드를 찾는데, 새 템플릿에 "GOSPEL"이 같은 슬라이드에 병기돼 있으면 텍스트가 "복 음"
단독이 아니게 되어 탐지가 깨질 수 있다 — 이런 지점을 전부 나열한다.

### 3. 성인/청년/어린이 공통 vs 분기 vs 신규 분류

`mass-template-architect` 에이전트 정의(`.claude/agents/mass-template-architect.md`)의 3단계
분류 기준(완전 공통 / 파라미터 분기 필요 / 완전 신규)에 따라 1~2단계 조사 결과를 분류한다.
빈 표만 채우지 말고, 각 항목마다 "왜 그렇게 분류했는지" 슬라이드 번호·텍스트를 근거로 남긴다.

### 4. 날짜/파일명 규칙 확인

`find_files()`가 참조 PPT를 찾는 방식(`^\d{8}_` 패턴, 오늘 날짜 미포함 `.pptx`)이 새 미사
유형/성당의 실제 파일명 규칙과 맞는지 확인한다. 예: 청년미사 기존 파일은 `DDMMYY.pptx`
(예: `180726.pptx` = 2026-07-18)로, 성인미사의 `YYYYMMDD_전례명.pptx`와 전혀 다른 규칙이다 —
이런 차이는 반드시 설계서에 명시한다.
