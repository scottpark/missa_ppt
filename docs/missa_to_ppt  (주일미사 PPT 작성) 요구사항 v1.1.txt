주일미사 PPT 작성 요구사항 v1.1
================================
작성일: 2026-06-30
이전 버전: docs/v1.0/주일미사 PPT 작성 요구사항.docx


[v1.0 대비 변경사항 요약]
1. 실행 방식: 인수 없이 실행 시 대화형 팝업 모드 추가
2. 입력 파일 선택: 날짜 폴더 자동 탐색 → 대화형 모드에서 직접 선택
3. 성가 PPT 위치: 날짜 폴더 → OneDrive 동기화 폴더 (중앙 관리)
4. 독서·복음 종료 슬라이드: "주님의 말씀입니다" 텍스트박스 위치 요구사항 추가


[개요]
한국천주교주교회의 매일미사 사이트(missa.cbck.or.kr)에서 날짜별 미사 내용을
가져와서, 이전 미사의 PPT 파일을 수정하여 새 미사 날짜의 PPT 파일을 만든다.


[실행 방식]

(A) 대화형 모드 — 인수 없이 실행: python missa_to_ppt.py
  팝업 순서:
  1. 미사 일자 입력 (YYYYMMDD 텍스트 입력)
  2. 파일 선택 화면 (참조 미사 PPT·시작기도 PPT·화답송 악보 PPT 한 화면)
     - 참조 미사 PPT: 필수
     - 시작기도 PPT: 선택 (취소 가능)
     - 화답송 악보 PPT: 필수
  3. 성가번호 입력 (입당·봉헌·성체·2차봉헌·파견)

(B) CLI 모드 — 인수 지정 실행 (기존 방식 유지):
  python missa_to_ppt.py YYYYMMDD [--입당 N --봉헌 N --성체 N --2차봉헌 N --파견 N]
  - 성가번호 생략 시 팝업으로 입력받음
  - 입력 파일은 날짜 폴더(YYYYMMDD/)에서 자동 탐색


[입력 파일]

1. 참조 미사 PPT
   - 이전 주일 미사 PPT (이번 미사의 기준 양식)
   - 대화형 모드: 직접 파일 선택
   - CLI 모드: YYYYMMDD/ 폴더에서 자동 탐색

2. 시작기도 PPT
   - 대화형 모드: 직접 파일 선택 (선택 사항)
   - CLI 모드: YYYYMMDD/ 폴더에서 자동 탐색

3. 화답송 악보 PPT
   - 대화형 모드: 직접 파일 선택 (필수)
   - CLI 모드: YYYYMMDD/ 폴더에서 자동 탐색

4. 성가 PPT (입당·봉헌·성체·2차봉헌·파견)
   - 실행 방식 무관하게 OneDrive 동기화 폴더에서 자동 탐색
   - 폴더 경로는 최초 1회 팝업으로 입력받아 config.json에 저장
   - 이후 실행 시 config.json에서 자동 로드 (팝업 없음)
   - OneDrive에서 찾지 못하면 날짜 폴더 fallback 탐색

5. 미사 JSON
   - missa_to_json.py를 실행해 자동 생성 (YYYYMMDD/missa_YYYYMMDD.json)


[처리 및 출력]

1. missa_to_json.py 실행 → JSON 생성 (이미 존재하면 재실행 생략)
2. 참조 PPT를 열어 JSON 내용으로 전례 텍스트 교체
   - 참조 PPT의 폰트·사이즈·위치·색상·양식 유지
3. 시작기도문 슬라이드 교체
4. 성가 슬라이드 교체 (5종)
5. 검증
6. 출력 파일 저장: YYYYMMDD/<liturgy>.pptx


[세부 요구사항]

1. 전례 텍스트 교체

1-1. 제목 슬라이드
  - 날짜(연·월·일)와 전례명(liturgy) 교체, 기존 포맷 유지

1-2. 입당송
  - content 앞에 "◎ \t" 추가

1-3. 독서·복음 공통
  - 본문 내 숫자(절 번호)는 오렌지색 (RGB: 255, 192, 0)
  - 같은 절 내 \n은 무시하고 이어서 표시
  - 슬라이드당 최대 25자/줄, 9줄; 초과 시 다음 슬라이드에서 이어서 표시
  - "주님의 말씀입니다." 등 종료 텍스트는 본문과 별도 처리

1-4. 독서·복음 종료 슬라이드 레이아웃
  - 마지막 슬라이드의 본문이 5줄 이하이면 종료 텍스트를 해당 슬라이드에 통합
  - "주님의 말씀입니다." 텍스트박스는 본문 마지막 줄로부터 두 줄 공백 후 배치
  - 제1독서·제2독서·복음 각각 독립적으로 위치 계산

1-5. 제1독서
  - 제목 슬라이드: 성서명만 교체 (절 번호 제거)
  - 본문 슬라이드: 내용 교체

1-6. 화답송
  - 악보 슬라이드(홀수)와 텍스트 슬라이드(짝수) 교대 배치
  - 악보 슬라이드: 화답송 악보 PPT에서 복사
  - 텍스트 슬라이드: 화답송 각 절 내용

1-7. 제2독서
  - 제목 슬라이드: 성서명만 교체
  - 본문 슬라이드: 내용 교체
  - JSON이 null이면 제2독서 슬라이드 전체 삭제

1-8. 복음환호송
  - 본문 교체

1-9. 복음
  - 제목 슬라이드: 복음사가 이름+조사 교체
  - 본문 슬라이드: 내용 교체

1-10. 영성체송
  - 본문 교체

2. 시작기도문 교체
  - 입당송 슬라이드 직전에 위치
  - 선택한 시작기도 PPT 슬라이드로 전체 교체

3. 성가 교체 (순서: 입당→봉헌→성체→2차봉헌→파견)
  - 성가 PPT 슬라이드를 원본 양식 그대로 복사
  - 슬라이드 상단 성가 타입 및 번호 업데이트
  - 여러 페이지 악보 전체 교체

4. 검증
  - liturgy 텍스트 존재 확인
  - 주요 섹션 슬라이드 존재 확인
  - 독서 절 번호 오렌지색 확인
