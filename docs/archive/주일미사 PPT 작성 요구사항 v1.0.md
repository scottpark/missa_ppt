# 주일미사 PPT 작성 요구사항 v1.0

## 1. 개요

한국천주교주교회의 매일미사 사이트(missa.cbck.or.kr)에서 날짜별 미사 내용을 가져와, 이전 미사 PPT 파일(참조 PPT)을 수정하여 새 미사날짜의 PPT 파일을 생성한다. 참조 PPT의 폰트·서식·레이아웃을 그대로 유지하며 텍스트와 슬라이드만 교체한다.

## 2. 입력

- 미사일자: YYYYMMDD
- 성가번호: 입당, 봉헌, 성체, 2차봉헌, 파견 (CLI 인수 또는 tkinter 팝업으로 입력)
- `YYYYMMDD/` 폴더 내 파일:
  - 참조 PPT 파일 (이전 미사 PPT, 파일명에 현재 날짜가 없는 것)
  - 시작기도문 PPT (파일명에 "시작기도" 포함)
  - 화답송 악보 PPT (파일명에 "화답송 악보" 포함)
  - 성가 PPT × 5 (파일명에 "성가 NNN" 포함)

## 3. 출력

- 출력 파일명: `YYYYMMDD_<liturgy>.pptx` (예: `20260628_연중 제13주일.pptx`)
- 출력 위치: `YYYYMMDD/` 폴더

## 4. 세부 요구사항

### 4-1. JSON 생성 (missa_to_json.py)

missa.cbck.or.kr에서 해당 날짜 미사 데이터를 크롤링하여 `YYYYMMDD/missa_YYYYMMDD.json`으로 저장한다.

- 섹션: 입당송, 제1독서, 화답송, 제2독서, 복음환호송, 복음, 영성체송
- 각 섹션 구조: `{ "title": ..., "content": ... }`
- 제1독서·제2독서·복음 content: "주님의 말씀입니다." 이후 전체 삭제, 나머지 `\n`을 스페이스 한 칸으로 대체 (연속 텍스트로 병합)
- 화답송·입당송·영성체송 content: `\n` 구분 유지

### 4-2. 전례 텍스트 교체

**제목 슬라이드**
- 날짜(년·월·일)와 liturgy 텍스트 교체, 기존 단락 서식 유지

**입당송**
- 본문 형식: `◎ \t` + content (탭 문자로 들여쓰기 정렬)
- 참조 PPT의 pPr(marL, indent, tabLst) 그대로 유지 — 별도 재계산 없음

**독서(제1독서·제2독서)·복음 공통**
- `CHARS_PER_LINE = 26`자 (32pt 바탕체 24.6cm 텍스트박스 기준)
- `LINES_PER_SLIDE = 8`줄
- 절 경계와 무관하게 8줄씩 꽉 채움 (절 번호가 줄 첫머리에 올 때만 오렌지색 적용)
- 절 번호(앞 숫자): 오렌지색 RGB (255, 192, 0)
- 마지막 슬라이드("주님의 말씀입니다." 등): 참조 PPT에서 보존, content 박스는 비움
- 제1독서·복음 마지막 슬라이드의 텍스트박스 위치·크기 → 제2독서 마지막 슬라이드 기준으로 정렬
- 제2독서가 없는 경우(JSON null) 해당 섹션 슬라이드 전체 삭제

**화답송**
- 슬라이드 패턴: [악보] - [절1] - [악보] - [절2] - [악보] - … (악보 슬라이드 반복)
- 악보 슬라이드: 화답송 악보.pptx 첫 슬라이드 복사 + 타이틀 교체
- 절 슬라이드: `○\t` + 절 내용 형식으로 교체
- 화답송 content의 첫 항목(◎ 후렴)은 악보 슬라이드에 포함되므로 절 슬라이드에서 제외

**복음환호송**
- Run-level 폰트 구조 보존: ◎ 줄 → 대한체, ○ 내용 → 바탕체
- 참조 PPT 단락(pPr, lnSpc, tabLst) deepcopy 후 텍스트만 교체
- ◎ 줄: 첫 알렐루야(`para[0]`)와 마지막 알렐루야(`para[2]`) 구분 적용
- ○ 줄: `para[1]` deepcopy 후 `run[0]`("○ \t") 유지, `run[1]`에 새 내용

**영성체송**
- 본문 텍스트 교체, 단락 서식 유지

### 4-3. 시작기도문 슬라이드 교체

- 위치: 입당송 슬라이드 직전
- 시작기도 앞 빈 슬라이드 한 장 보존 (삭제하지 않음)
- 기존 시작기도 슬라이드 전체를 시작기도문.pptx 슬라이드로 교체
- 교체된 각 슬라이드 배경을 검정으로 강제 설정 (p:bg + 전체 크기 검정 사각형 오버레이)

### 4-4. 성가 슬라이드 교체

- 순서: 입당 → 봉헌 → 성체 → 2차봉헌 → 파견
- 각 성가: 성가 NNN.pptx 슬라이드 전체를 원본 서식 그대로 복사·교체
- 슬라이드 상단 성가 타입 텍스트 확인, 다를 경우 수정 (run 서식 보존)
- 성가번호 수정 (run 서식 보존)

## 5. 서식 보존 원칙

- 슬라이드 복사 시 shape 트리, 이미지 관계(image/hdphoto), 배경(p:bg) 모두 복사
- 텍스트 교체 시 기존 run의 rPr(폰트명·크기·색상·효과) 보존 (deepcopy clone 방식)
- 단락 교체 시 pPr(marL, indent, lnSpc, tabLst) 보존
- 새 슬라이드 삽입 시 기존 content 슬라이드를 template으로 복제

## 6. 검증

- liturgy 텍스트가 PPT에 포함되는지 확인
- 입당송·화답송·영성체송 슬라이드 존재 확인
- 독서 내 절 번호 오렌지색 여부 확인
