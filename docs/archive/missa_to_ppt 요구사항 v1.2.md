## v1.1 대비 변경사항 요약

1. 평일미사 지원 추가: 날짜 기반 자동 미사 유형 판단 (일요일 → 주일미사, 그 외 → 평일미사)
2. UI 재구성: 두 팝업 화면의 항목 순서 변경 + 미사 후 기도 PPT 입력란 신규 추가
3. 화답송 처리: 주일(악보+텍스트) / 평일(텍스트 전용) 분기
4. 성가 처리: 평일은 번호 슬라이드만 유지, 악보 슬라이드 복사 생략
5. 미사 후 기도: 평일미사 한정, 파견성가 다음에 별도 PPT 슬라이드 삽입

## 개요

한국천주교주교회의 매일미사 사이트(missa.cbck.or.kr)에서 날짜별 미사 내용을 가져와서, 이전 미사의 PPT 파일을 수정하여 새 미사 날짜의 PPT 파일을 만든다. 주일미사와 평일미사 모두 지원하며, 입력 날짜의 요일로 미사 유형을 자동 판단한다.

## 미사 유형 자동 판단

- 입력 날짜가 일요일이면 → 주일미사 처리
- 입력 날짜가 일요일이 아니면 → 평일미사 처리
- 사용자가 별도로 미사 유형을 선택하지 않음
- 처리 시작 시 "미사 유형: 주일미사 / 평일미사" 로그 출력

## 실행 방식

### (A) 대화형 모드 — 인수 없이 실행

```
python missa_to_ppt.py
```

팝업 순서:

1. 미사 일자 입력 (YYYYMMDD 텍스트 입력)
2. 파일 선택 화면 [첫 번째 팝업]
   - 참조 미사 PPT: 필수
   - 화답송 악보 PPT: 선택 (주일미사에만 필요; 미입력 시 경고 후 진행 확인)
   - 시작기도 PPT: 선택
   - 미사 후 기도 PPT: 선택 (평일미사에만 사용)
3. 성가번호 입력 [두 번째 팝업] (입당·봉헌·성체·2차봉헌·파견)

### (B) CLI 모드 — 인수 지정 실행 (기존 방식 유지)

```
python missa_to_ppt.py YYYYMMDD [--입당 N --봉헌 N --성체 N --2차봉헌 N --파견 N]
```

- 성가번호 생략 시 팝업으로 입력받음
- 입력 파일은 날짜 폴더(`YYYYMMDD/`)에서 자동 탐색

## 입력 파일

1. **참조 미사 PPT**
   - 이전 미사 PPT (이번 미사의 기준 양식)
   - 대화형 모드: 직접 파일 선택 (필수)
   - CLI 모드: `YYYYMMDD/` 폴더에서 자동 탐색

2. **화답송 악보 PPT**
   - 대화형 모드: 직접 파일 선택 (선택; 주일미사에서 미입력 시 경고)
   - CLI 모드: `YYYYMMDD/` 폴더에서 자동 탐색
   - 평일미사: 사용하지 않음

3. **시작기도 PPT**
   - 대화형 모드: 직접 파일 선택 (선택)
   - CLI 모드: `YYYYMMDD/` 폴더에서 자동 탐색

4. **미사 후 기도 PPT**
   - 평일미사 전용; 주일미사에는 사용하지 않음
   - 대화형 모드: 직접 파일 선택 (선택)
   - CLI 모드: `YYYYMMDD/` 폴더에서 자동 탐색

5. **성가 PPT** (입당·봉헌·성체·2차봉헌·파견)
   - 실행 방식 무관하게 OneDrive 동기화 폴더에서 자동 탐색
   - 폴더 경로는 최초 1회 팝업으로 입력받아 `config.json`에 저장
   - 이후 실행 시 `config.json`에서 자동 로드 (팝업 없음)
   - OneDrive에서 찾지 못하면 날짜 폴더 fallback 탐색
   - 평일미사: 번호 슬라이드만 갱신하며 악보 슬라이드는 복사하지 않음

6. **미사 JSON**
   - `missa_to_json.py`를 실행해 자동 생성 (`YYYYMMDD/missa_YYYYMMDD.json`)

## 처리 및 출력

### 공통 처리 (주일·평일 동일)

1. `missa_to_json.py` 실행 → JSON 생성 (이미 존재하면 재실행 생략)
2. 참조 PPT를 열어 JSON 내용으로 전례 텍스트 교체 (제목 슬라이드, 입당송, 제1독서, 제2독서, 복음환호송, 복음, 영성체송)
3. 시작기도문 슬라이드 교체 (파일 지정 시)
4. 성가 슬라이드 처리 (5종)
5. 검증
6. 출력 파일 저장: `YYYYMMDD/{liturgy}.pptx`

### 주일미사 추가 처리

- 화답송: 화답송 악보 PPT에서 악보 슬라이드 복사 + 텍스트 슬라이드 배치

### 평일미사 추가 처리

- 화답송: 텍스트 슬라이드만 배치 (악보 없음)
- 미사 후 기도: 파견성가 다음에 별도 PPT 슬라이드 삽입 (파일 지정 시)

## 세부 요구사항

### 1. 전례 텍스트 교체

**1-1. 제목 슬라이드**
- 날짜(연·월·일)와 전례명(liturgy) 교체, 기존 포맷 유지

**1-2. 입당송**
- content 앞에 "◎ \t" 추가

**1-3. 독서·복음 공통**
- 본문 내 숫자(절 번호)는 오렌지색 (RGB: 255, 192, 0)
- 같은 절 내 `\n`은 무시하고 이어서 표시
- 슬라이드당 최대 9줄; 초과 시 다음 슬라이드에서 이어서 표시 (줄 수는 단어 경계 word-wrap 기준으로 계산)
- "주님의 말씀입니다." 등 종료 텍스트는 본문과 별도 처리

**1-4. 독서·복음 종료 슬라이드 레이아웃**
- 마지막 슬라이드의 본문이 5줄 이하이면 종료 텍스트를 해당 슬라이드에 통합
- "주님의 말씀입니다." 텍스트박스는 본문 마지막 줄로부터 두 줄 공백 후 배치
- 제1독서·제2독서·복음 각각 독립적으로 위치 계산

**1-5. 제1독서**
- 제목 슬라이드: 성서명만 교체 (절 번호 제거)
- 본문 슬라이드: 내용 교체

**1-6. 화답송**

- 주일미사
  - 악보 슬라이드(홀수)와 텍스트 슬라이드(짝수) 교대 배치
  - 악보 슬라이드: 화답송 악보 PPT에서 복사
  - 텍스트 슬라이드: 화답송 각 절 내용

- 평일미사
  - 텍스트 슬라이드만 배치 (악보 슬라이드 없음)
  - 참조 PPT의 화답송 텍스트 템플릿 슬라이드 포맷 사용 (템플릿 슬라이드는 `find_sections()`으로 동적 탐지 — 슬라이드 번호 고정 불가)
  - 후렴(◎)도 텍스트로 표시
  - 화답송 제목 갱신은 주일·평일 공통

**1-7. 제2독서**
- 제목 슬라이드: 성서명만 교체
- 본문 슬라이드: 내용 교체
- JSON이 null이면 제2독서 슬라이드 전체 삭제
- 평일미사에서는 제2독서가 없는 경우가 일반적

**1-8. 복음환호송**
- 본문 교체

**1-9. 복음**
- 제목 슬라이드: 복음사가 이름+조사 교체
- 본문 슬라이드: 내용 교체

**1-10. 영성체송**
- 본문 교체

### 2. 시작기도문 교체

- 입당송 슬라이드 직전에 위치
- 선택한 시작기도 PPT 슬라이드로 전체 교체

### 3. 성가 처리 (순서: 입당→봉헌→성체→2차봉헌→파견)

- 주일미사
  - 성가 PPT 슬라이드를 원본 양식 그대로 복사 (악보 포함)
  - 슬라이드 상단 성가 타입 및 번호 업데이트

- 평일미사
  - 성가 번호 슬라이드 갱신 (성가 타입 및 번호 업데이트)
  - 악보 슬라이드는 복사하지 않으며, 참조 PPT에 남아 있는 기존 악보 슬라이드 삭제

### 4. 미사 후 기도 (평일미사 전용)

- 파견성가 다음에 별도 PPT 슬라이드들을 순서대로 삽입
- 원본 서식(이미지·배경 포함) 그대로 복사
- 파일 미지정 시 생략 (오류 아님)

### 5. 검증

- liturgy 텍스트 존재 확인
- 주요 섹션 슬라이드 존재 확인
- 독서 절 번호 오렌지색 확인
- 평일미사: 화답송 텍스트 슬라이드 존재 확인; 성가 악보 슬라이드 부재 확인
