성가 PPT 품질 개선 구현 계획 v1.0
====================================
작성일: 2026-07-01
요구사항: docs/성가 PPT 품질 개선 요구사항 v1.0.txt


[파일 구조]

missa_ppt/
└── enhance_hymn.py       ← 단일 스크립트


[실행 방법]

  python enhance_hymn.py "경로/성가123.pptx"

출력: ./성가/<원본파일명>.pptx


[사용 라이브러리]

- python-pptx : PPT 읽기/쓰기, 이미지 shape 및 관계(rId) 접근
- Pillow       : 이미지 열기, 업스케일(LANCZOS), Gaussian Blur
- numpy        : Otsu 임계값 계산, morphological 연산 (cv2·scipy 불필요)


[처리 파이프라인]

이미지 1장 기준:

  1. 이미지 열기 (Pillow, 그레이스케일 변환)
  2. 2배 업스케일 (LANCZOS)
       이유: 평균 획 두께 4px → 8px 확보, 이후 처리 정밀도 향상
  3. Gaussian Blur (radius=0.8)
       이유: JPEG 압축 아티팩트 완화 후 이진화 시 경계 노이즈 감소
  4. Otsu 이진화
       이유: 회색 중간값 픽셀 제거, 획을 순수 흑백으로 명확화
  5. Morphological Closing (3×3 커널: dilation → erosion)
       이유: 이진화 후 남은 획 끊김 연결
  6. PNG 저장
       이유: 흑백 이진 이미지에서 JPEG보다 무손실·고압축


[주요 함수]

otsu_threshold(arr)
  - numpy histogram으로 Otsu 임계값 계산
  - 반환: 정수 threshold

morphological_op(mask, ksize, dilate)
  - dilate=True: dilation, dilate=False: erosion
  - numpy pad + 슬라이딩 윈도우로 구현 (scipy 미사용)

enhance_image(image_bytes) -> bytes
  - 위 파이프라인 전체 실행
  - 입력: 원본 이미지 바이트, 출력: PNG 바이트

process_pptx(input_path)
  - PPT 열기 → 슬라이드/shape 순회
  - 각 PICTURE shape의 image_part._blob 교체
  - 처리 불가 이미지는 예외 처리 후 계속 진행
  - ./성가/ 폴더에 저장

main()
  - argparse로 input 경로 수신
  - 파일 존재 여부 및 .pptx 확장자 검사


[PPT 이미지 교체 방식]

python-pptx 내부 구조를 직접 수정:

  pic = shape._pic
  blip = pic.find('.//' + qn('a:blip'))
  rId = blip.get(qn('r:embed'))
  image_part = slide.part.related_parts[rId]
  image_part._blob = enhanced_png_bytes

슬라이드 레이아웃(위치·크기)은 shape 레벨에서 관리되므로 변경 없음.
