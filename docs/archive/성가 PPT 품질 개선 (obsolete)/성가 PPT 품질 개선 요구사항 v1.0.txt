성가 PPT 품질 개선 요구사항 v1.0
==================================
작성일: 2026-07-01


[개요]
스캔된 성가 악보 PPT 파일의 이미지 품질을 개선하는 스크립트.
슬라이드 내 이미지에 포함된 한글 가사의 획 끊김, 굵기 불균일,
노이즈 등 저해상도 스캔으로 인한 품질 저하를 개선한다.


[입력]

- 성가 악보 .pptx 파일 경로 (CLI 인수)
- 파일 형식: .pptx 전용


[이미지 구조]

- 슬라이드 한 장에 악보와 한글 가사가 같은 이미지 안에 존재
- 배치 패턴: 악보 → 가사 → 악보 → 가사 반복
- 가사는 악보 사이에 섞여 있으며 특정 영역에 고정되지 않음


[품질 문제 원인]

- 원본 스캔 DPI 낮음 (확인된 샘플: 96 DPI)
- JPEG 압축으로 인한 추가 열화
- 결과: 한글 획 두께 평균 4px 수준 → 얇은 획(1~2px)이 끊어지거나 소실됨


[주요 기능]

1. PPT 전체 슬라이드에서 이미지 shape 자동 추출
2. 각 이미지에 품질 개선 처리 적용
   - 악보 영역과 가사 영역을 구분하지 않고 전체 이미지에 동일 처리
   - 처리 후 악보 및 가사 모두 품질 향상
3. 처리된 이미지로 원본 슬라이드 이미지 교체
4. 슬라이드 레이아웃(이미지 위치·크기) 변경 없음


[출력]

- 저장 위치: 스크립트 실행 디렉터리 하위 성가/ 폴더
- 파일명: 원본 파일명 그대로 유지
- 폴더가 없으면 자동 생성


[처리 불가 이미지]

- Pillow로 열 수 없는 형식(예: WDP/HD Photo)은 건너뛰고 경고 출력
- 처리 실패한 슬라이드가 있어도 나머지는 계속 처리
