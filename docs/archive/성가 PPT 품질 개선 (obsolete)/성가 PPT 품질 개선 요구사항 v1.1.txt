성가 PPT 품질 개선 요구사항 v1.1
==================================
작성일: 2026-07-01
이전 버전: docs/성가 PPT 품질 개선 요구사항 v1.0.txt


[v1.0 대비 변경사항 요약]
1. 실행 방식: CLI 인수 없을 때 파일 선택 팝업 추가
2. 출력 파일명: 원본 파일명 + "_enhanced" 접미사
3. 검증 루틴: 이미지 처리 후 정상 개선 여부 자동 확인
4. 에러 보고: 처리 중 발생한 모든 오류/경고를 사용자에게 명확히 전달


[개요]
스캔된 성가 악보 PPT 파일의 이미지 품질을 개선하는 스크립트.
슬라이드 내 이미지에 포함된 한글 가사의 획 끊김, 굵기 불균일,
노이즈 등 저해상도 스캔으로 인한 품질 저하를 개선한다.


[실행 방식]

(A) CLI 모드 — 파일 경로를 인수로 전달:
  python enhance_hymn.py "경로/성가123.pptx"

(B) 대화형 모드 — 인수 없이 실행:
  python enhance_hymn.py
  → tkinter 파일 선택 팝업 자동 표시
  → 취소 시 오류 메시지 출력 후 종료


[입력]

- 성가 악보 .pptx 파일
- 파일 형식: .pptx 전용
- 파일 미존재 또는 형식 오류 시 즉시 오류 메시지 출력 후 종료


[이미지 구조]

- 슬라이드 한 장에 악보와 한글 가사가 같은 이미지 안에 존재
- 배치 패턴: 악보 → 가사 → 악보 → 가사 반복
- 악보 영역과 가사 영역을 구분하지 않고 전체 이미지에 동일 처리 적용


[품질 문제 원인]

- 원본 스캔 DPI 낮음 (확인된 샘플: 96 DPI)
- JPEG 압축으로 인한 추가 열화
- 결과: 한글 획 두께 평균 4px 수준 → 얇은 획(1~2px)이 끊어지거나 소실됨


[주요 기능]

1. PPT 전체 슬라이드에서 이미지 shape 자동 추출
2. 각 이미지에 품질 개선 처리 적용 (악보·가사 구분 없이 동일 처리)
3. 처리된 이미지로 원본 슬라이드 이미지 교체
4. 슬라이드 레이아웃(이미지 위치·크기) 변경 없음
5. 각 이미지 처리 후 개선 여부 자동 검증
6. 처리 결과 요약(성공·경고·실패) 출력


[검증 루틴]

각 이미지 처리 후 아래 항목을 자동 확인:
  - 처리된 이미지를 Pillow로 재오픈 가능한지 (파일 무결성)
  - 어두운 픽셀 비율이 0.5% 미만 → "이미지가 거의 흰색" 경고
  - 어두운 픽셀 비율이 80% 초과 → "이미지가 거의 검정" 경고
  - 처리 전후 어두운 픽셀 비율 차이가 50%p 초과 → "큰 변화" 경고

검증 결과는 슬라이드별로 기록하여 처리 완료 후 요약에 포함.


[에러 보고]

처리 중 발생 가능한 오류 유형:
  - 이미지를 Pillow로 열 수 없음 (미지원 형식: WDP 등)
  - Otsu 임계값 계산 실패 (단색 이미지 등)
  - 이미지 교체 중 PPT 내부 오류
  - 검증 단계에서 비정상 결과 감지

보고 방식:
  - 각 오류 발생 시 슬라이드 번호와 원인을 즉시 콘솔 출력
  - 처리 완료 후 전체 요약 출력:
      처리 완료: N장
      경고: N장 (슬라이드 번호 목록)
      실패: N장 (슬라이드 번호 및 원인 목록)
  - 실패한 슬라이드는 원본 이미지 그대로 유지


[출력]

- 저장 위치: 스크립트 실행 디렉터리 하위 성가/ 폴더 (없으면 자동 생성)
- 파일명: 원본 파일명 + "_enhanced" 접미사
    예) 성가123.pptx → 성가/성가123_enhanced.pptx
