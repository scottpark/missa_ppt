# PRD — 미사 PPT 자동 생성 도구

> 한 장 요구사항. 기능별 동작·인수 기준은 `SPECS/`, 구조는 `ARCHITECTURE.md`, 진행 중 작업은 `IMPLEMENTATION_PLAN.md`.
> 2026-10-06 새 문서 체계로 이관(기존 요구사항 문서는 `archive/legacy-2026-10-06/`).

## 1. 문제와 이유
성당 미사 준비 담당자(운영자)가 매주 매일미사 웹(missa.cbck.or.kr)의 독서·화답송·복음 등을 이전 미사 PPT에
손으로 옮기고, 성가 악보 슬라이드를 찾아 끼우고, 줄 수를 맞추는 데 긴 시간을 쓴다. 날짜와 성가 번호만 주면
참조 PPT의 서식을 그대로 유지한 채 새 미사 PPT를 자동으로 만들어 준다.

## 2. 목표와 성공 기준
- 입력(날짜 + 성가 번호/선택 + 참조·보조 PPT)만으로 **수정 없이 바로 쓸 수 있는** 결과 PPT를 만든다.
- 성공 기준
  - 독서·복음 본문 슬라이드가 마지막 1장을 제외하고 정확히 9줄이며 오버플로가 없다(PowerPoint 실측 기준).
  - 절 번호 오렌지색, 참조 PPT의 폰트·배경·레이아웃이 그대로 보존되고 PowerPoint가 '손상' 없이 연다.
  - 운영자가 `.bat` 더블클릭 → 파일 선택 → 결과 확인까지 개발자 도움 없이 수행한다.
  - 회귀 테스트(`pytest tests/`)가 통과한다.

## 3. 비목표 (하지 않을 것)
- 웹 서비스/서버 배포 (로컬 실행 + GitHub 자동 업데이트로 확정).
- exe 배포 (2026-10-05 폐기, Python 소스 zip + `.bat`).
- 결과 PPT의 OneDrive 자동 업로드 (운영자 검증 후 결과창 버튼으로만).
- PPT 템플릿 자체 제작·편집 UI, 성가 악보 신규 제작(저화질 스캔 보정 포함).
- 성인·청년 외 미사 유형은 지원 요청이 있을 때만 별도 SPEC으로 추가.

## 4. 핵심 기능과 우선순위
| 우선순위 | 기능 | SPEC |
|---|---|---|
| MVP (완료) | 성인미사(주일·평일) PPT 생성 | `SPEC_성인미사.md`, `SPEC_공통_실행환경.md` |
| MVP (완료) | 독서·복음 슬라이드 단위 9줄 채우기 | `SPEC_독서복음_본문처리.md` |
| MVP (완료) | 공지사항 슬라이드·실행 아이콘 | `SPEC_공지사항_및_아이콘.md` |
| 완료 | 청년미사(영문 복음, 성가 5종×4출처, OneDrive 연동) | `SPEC_청년_*.md` |
| 다음 | 어린이미사 | (착수 시 `SPEC_어린이미사.md` 작성) |

## 5. 제약
- 기술 스택: Python, python-pptx/lxml(OOXML 직접 조작), Tkinter GUI, Windows PowerPoint COM(줄 수 실측; 불가 시 Pillow 폴백), Microsoft Graph(청년 OneDrive 폴백).
- 비용: 무료 범위(GitHub public 저장소, 성당 공용 계정). 외부 유료 서비스 없음.
- 시간: 개인(비전업) 작업 — 한 번에 한 미사 유형, 작은 변경은 SPEC 없이 체크리스트로 처리.
- 환경: Windows 운영자 PC, Python 설치 필요, PowerPoint 설치 권장.
