# 성인미사 PPT 자동 생성 프로그램 — 운영자 안내서

## 이 프로그램이 하는 일

그날의 독서·복음·화답송 본문을 매일미사 웹페이지에서 자동으로 가져오고, 성당 공용 OneDrive('PPT 문서'
폴더)의 참조 미사 PPT·시작기도·화답송 악보·공지사항·미사 후 기도·성가 파일을 이용해 **성인미사(주일·평일)
PPT**를 자동으로 만들어 줍니다.

> **이전에 `missa_to_ppt.exe`를 쓰셨다면**: 이 배포판부터는 exe가 아니라 Python으로 실행하는 방식입니다(청년미사와
> 동일). 아래 [부록 G](#g-이전-exe-버전에서-옮겨올-때)를 먼저 읽어 주세요.

## 최초 1회 준비 (컴퓨터당 한 번만)

1. **Python 설치**
   - [python.org/downloads](https://www.python.org/downloads/)에서 최신 버전을 내려받아 설치합니다.
   - 설치 화면 맨 아래의 **"Add python.exe to PATH"** 체크박스를 반드시 체크한 뒤 설치합니다(빠뜨리면 실행이
     안 됩니다).
2. **프로그램 폴더 압축 풀기**: 전달받은 `missa_ppt_성인미사.zip`을 원하는 위치에 압축을 풉니다.
3. **필요 패키지 설치**: 그 폴더 안의 **`install.bat`**을 더블클릭합니다. 검은 창이 뜨면서 필요한 프로그램들을
   자동으로 설치하고 **"성인미사 PPT" 바로가기**를 만듭니다 — "설치가 완료되었습니다" 문구가 뜨면 창을 닫아도
   됩니다.

여기까지가 최초 1회만 하면 되는 준비 과정입니다.

## 매번 실행하는 방법

1. 프로그램 폴더 안(또는 바탕화면에 옮겨 둔)의 **"성인미사 PPT" 바로가기**를 더블클릭합니다. (바로가기가 없으면
   폴더 안 `run_missa_성인.bat`을 더블클릭합니다.)
2. **최초 실행 시에만** "'PPT 문서' 폴더를 선택해 주세요" 창이 뜹니다. 이 컴퓨터에서 동기화 중인 OneDrive의
   **'PPT 문서'(성당 PPT 문서) 폴더 하나**를 선택하세요. 한 번 선택하면 저장되어 다시 묻지 않습니다. 성가·결과
   저장 위치는 프로그램이 이 폴더 아래에서 알아서 찾습니다.
   - 선택한 폴더 안에 `09.가톨릭 성가` 폴더가 있어야 합니다(없으면 다시 선택하라는 안내가 뜹니다).
   - **취소하면** 이번에는 기존 방식(성가 폴더를 직접 지정하거나 OneDrive 로그인)으로 진행됩니다(부록 C 참고).
3. **미사 일자**(예: 20261004)를 입력하고, '찾아보기'로 이번 미사의 파일을 고릅니다.

   | 항목 | 필수 | '찾아보기'가 시작하는 폴더 |
   |---|---|---|
   | 참조 미사 PPT | 필수 | `10.기타 PPT문서\PPT 자동화\1.Template` |
   | 시작기도 PPT | 선택 | `13.기도문` |
   | 화답송 악보 PPT/사진 | 주일미사에 필요(없으면 계속할지 묻습니다) | 처음에는 'PPT 문서', 이후에는 **직전에 고른 폴더** |
   | 공지사항 PPT | 선택(`.pptx`만 가능) | `11.공지사항 PPT문서` |
   | 미사 후 기도 PPT | 선택 | `13.기도문` |

4. **확인**을 누르면 **성가 번호** 입력 창이 뜹니다: 입당·봉헌·성체·2차봉헌·파견(주일은 5종 모두, 평일은 2차봉헌
   제외 4종). 숫자만 입력합니다.
5. 자동으로 PPT가 만들어집니다. 처음 5초 동안 진행 창 맨 위에 "PowerPoint가 백그라운드에서 실행됩니다" 안내가
   함께 보입니다.
6. 끝나면 결과 창이 뜹니다. 버튼은 왼쪽부터 **[파일 열기] [원드라이브로 복사] [폴더 열기] [닫기]**입니다. 파일을
   열어 내용을 확인한 뒤 [원드라이브로 복사]를 눌러 OneDrive에 올립니다.

## 결과 파일 위치

- 프로그램 폴더의 `output\{날짜}\` 안에 저장됩니다(예: `output\20261004\20261004_연중 제27주일.pptx`).
- 프로그램이 OneDrive에 자동으로 올리지는 않습니다. 결과 창의 **[원드라이브로 복사]**를 누르면 'PPT 문서' 폴더 아래
  `{연도(YYYY)}\`에 저장되고(연도 폴더가 없으면 자동으로 만듭니다), 저장된 폴더를 안내해 줍니다. 같은 이름의 파일이
  이미 있으면 덮어쓸지 먼저 묻습니다. OneDrive 앱이 알아서 동기화합니다.
- 버튼을 쓰지 않고 `output` 폴더의 파일을 직접 올려도 됩니다.

## 문제가 생기면

화면의 오류 메시지를 캡처해서 개발 담당자에게 전달해 주세요. 아래 부록에 설치·실행 관련 자세한 내용과 흔한 문제를
정리해 두었습니다.

# 부록 (Appendix)

## A. Python 설치 확인 방법

시작 메뉴에서 **"명령 프롬프트"**(또는 PowerShell)를 열고 아래처럼 입력해 봅니다.

```
python --version
```

`Python 3.x.x` 같은 버전이 나오면 정상입니다. `'python'은(는) 내부 또는 외부 명령...` 같은 오류가 나오면 설치 시
"Add python.exe to PATH" 체크를 빠뜨린 것이니, Python을 다시 설치하면서 그 항목을 꼭 체크합니다.

## B. `install.bat`을 실행했는데 오류가 난다면

- "패키지 설치에 실패했습니다"가 뜨면 대부분 Python/PATH 설정 문제입니다 — 부록 A를 먼저 확인합니다.
- 그래도 안 되면 검은 창에 나온 오류 메시지 전체를 캡처해 개발 담당자에게 전달합니다.

## C. 'PPT 문서' 폴더를 선택하지 않았을 때 (성가 폴더·OneDrive 로그인)

기본 방식은 'PPT 문서' 폴더를 직접 선택하는 것이라 **로그인이 필요 없습니다**. 폴더 선택창에서 취소했거나 이 컴퓨터에
동기화 폴더가 없으면, 프로그램은 성가 파일을 찾기 위해 성당 공용 계정으로 OneDrive에 로그인하는 방식을 씁니다.

- 가능하면 OneDrive 앱에서 성당 공용 폴더를 먼저 동기화한 뒤 프로그램을 다시 실행해 폴더를 선택하세요(로그인 방식은
  훨씬 느립니다).
- 설정한 폴더를 바꾸고 싶으면 프로그램 폴더의 `config.json`에서 `onedrive_ppt_folder`(와 `onedrive_hymn_folder`)
  항목을 삭제한 뒤 다시 실행하면 선택창이 다시 뜹니다.
- 로그인은 **컴퓨터/사용자 계정당 최초 1회**만 필요합니다.
- **로그인 링크는 반드시 새 시크릿 창(크롬 `Ctrl+Shift+N` / 엣지 InPrivate `Ctrl+Shift+N`)에서 여세요.** 평소 쓰던
  창에서 열면 그 브라우저에 로그인돼 있는 **다른 개인 Microsoft 계정으로 자동 로그인**될 수 있습니다. 그렇게 넘어갔다면
  로그인 화면에서 **"다른 계정 사용"**을 눌러 성당 공용 계정을 입력하세요.
- 공용 계정 비밀번호는 개발 담당자 또는 담당 사목회에 문의합니다.

## D. 실행 중 PowerPoint 관련 안내

프로그램이 줄 수를 정확히 맞추기 위해 PowerPoint를 화면에 보이지 않게(백그라운드로) 잠깐 실행합니다(처리가 시작되면
진행 창 맨 위에 5초 동안 안내가 표시됩니다). 작업표시줄에 PowerPoint 아이콘이 잠깐 나타날 수 있는데, 지금 하던 작업의
포커스를 빼앗지는 않으니 그대로 두시면 됩니다. 같은 이름의 PPT가 PowerPoint에서 열려 있으면 저장이 안 되니 먼저
닫아 주세요.

## E. 버전 확인과 업데이트

입력 화면 하단에 `20261005-01` 같은 형식의 버전 번호가 표시됩니다. 옆의 **"🔄 업데이트 확인"** 링크를 누르면 최신
버전이 있는지 확인하고 받을 수 있습니다(설정·`output` 폴더는 건드리지 않습니다). 문의 시 이 번호를 함께 알려주세요.

## F. 다시 설치해야 할 때

프로그램 폴더 전체를 삭제하고 새 zip을 풀어 최초 1회 준비 과정(Python 설치는 한 번 해뒀다면 건너뛰고,
`install.bat`부터)만 다시 하면 됩니다. 예전 설정을 유지하려면 지우기 전에 `config.json`을 따로 복사해 뒀다가 새 폴더에
넣으세요.

## G. 이전 exe 버전에서 옮겨올 때

예전에 쓰던 `missa_to_ppt.exe`(와 `assets` 폴더)는 더 이상 업데이트되지 않으니 새 방식으로 바꿔 주세요.

1. 위 '최초 1회 준비'를 진행합니다(Python 설치 → zip 압축 풀기 → `install.bat`).
2. **예전 exe 폴더의 `config.json`**을 새 프로그램 폴더로 복사하면 성가 폴더 등 기존 설정이 그대로 이어집니다(복사하지
   않으면 첫 실행 때 'PPT 문서' 폴더를 다시 한 번 선택하면 됩니다).
3. 예전 `output` 폴더의 결과물이 필요하면 새 폴더의 `output`으로 옮깁니다.
4. 새 바로가기가 잘 동작하는 것을 확인한 뒤 예전 exe와 바로가기는 지워도 됩니다.
