## 2026-10-02 — 청년미사 OneDrive 접속 방식: 로컬 폴더 우선, 로그인 폴백 (확정·구현 완료)

10/3 청년미사 실사용에서 성가 단계가 2~3분 걸린 원인이 곡 생성이 아니라 Graph API 호출(호출당
약 3초, 곡마다 목록 조회+다운로드 순차 반복)로 확인됨. 성능 개선(병렬화 등)은 하지 않기로 하고,
성인미사처럼 로컬 OneDrive 동기화 폴더를 직접 읽는 방식을 1순위로 전환하기로 결정. 확정 사항:
'PPT 문서' 폴더 하나만 입력(`onedrive_ppt_folder`, 첫 실행 시 폴더 선택창), 설정 없음/폴더 없음/
선택 취소 시 기존 기기 코드 로그인으로 폴백, 가톨릭성가는 `09.가톨릭 성가/성가-악보버전` 유지,
나주노·야훼이레는 `20.청년 미사/2.성가/{나주노|야훼이레} 성가`(실제 폴더명 `2.성가`), 4개 파일
선택은 로컬 파일창, 결과는 로컬 `output/` 유지 + `20.청년 미사/{YYYY}/`(없으면 생성)에 복사.
본문 반영: `docs/missa_to_ppt 요구사항.md` §3.3.1·§3.3·§3.4·§3.8, `README_청년미사_운영자.md`.
