# SPEC: OneDrive 폴더 구조 개편 대응 (2026-10-18, 확정·구현 완료)

> 범위: 'PPT 문서' 단일 루트 가정을 버리고, 새 3분할 폴더 구조와 운영자 권한 구분을 지원한다.
> 영향받는 기존 절(이 문서 기준으로 고쳐 썼다): `SPEC_공통_실행환경.md` §1.9,
> `SPEC_성인미사.md` §2.1(C), `SPEC_청년_OneDrive.md` §3.3·§3.3.1·§3.4, `SPEC_청년_성가.md`(성가 PPT 저장 위치).
> 구현 방식은 쓰지 않는다(ARCHITECTURE 단계에서 다룬다).

## 1. 배경

OneDrive 'PPT 문서' 폴더가 아래처럼 개편됐다(2026-10-18 실제 폴더에서 확인).

```
PPT 문서/
├─ 00.공용 PPT/   09.가톨릭 성가/{성가-악보버전, 성가-반주곡…}  11.공지사항 PPT문서/  13.기도문/
├─ 10.성인 미사/  01.주일 미사(3년주기)… 10.기타 PPT문서/PPT 자동화/1.Template  14.화답송 악보/  2026/ …
└─ 20.청년 미사/  1.Template/  2.성가/{나주노 성가, 야훼이레 성가}  2026/ …
```

이전에는 `PPT 문서/09.가톨릭 성가`, `/11.공지사항 PPT문서`, `/13.기도문`, `/10.기타 PPT문서/…`, `/14.화답송 악보`, `/{YYYY}`(성인 결과), `/20.청년 미사`가
모두 'PPT 문서' 바로 아래에 있었다. 지금 PC의 `config.json`(`onedrive_hymn_folder` 등)은 옛 위치를 가리켜 **현재 구조에서는 무효**다.

**운영자 권한이 둘로 나뉜다.**
- 마스터 운영자(상위 'PPT 문서'에 직접 권한): 로컬에 `PPT 문서` 전체가 동기화돼 있다.
- 그 외 운영자: `00.공용 PPT`와 본인 담당 미사 폴더만 받는다(청년 운영자 = `00.공용 PPT` + `20.청년 미사`, 향후 어린이 운영자 = `00.공용 PPT` + `30.어린이 미사`(가칭)).
  이 두 폴더는 로컬에서 **서로 다른 위치(공통 부모 없음)**에 있을 수 있다 → 'PPT 문서' 하나만 입력받는 현재 방식은 성립하지 않는다.

## 2. 동작 요구

### 2.1 폴더 설정: 루트 3종을 각각 저장한다
- 설정 단위는 **세 루트 폴더**다: 공용(`00.공용 PPT`), 성인(`10.성인 미사`), 청년(`20.청년 미사`). 각 로컬 절대경로를 `config.json`에 저장한다.
- 성인 실행은 공용+성인, 청년 실행은 공용+청년만 필요하다. **필요하지 않은 루트는 묻지 않는다**(청년 운영자에게 성인 폴더를 묻지 않음).
- 필요한 루트가 없거나(미설정) 가리키는 폴더가 없으면(이동·삭제·동기화 해제) 시작 시 폴더 선택창을 띄운다. 폴더 이름은 공백 유무 차이를 무시하고 검증한다.
  각 루트는 안에 기대하는 하위 폴더가 있어야 유효하다(공용: `09.가톨릭 성가` / 성인: `10.기타 PPT문서` / 청년: `2.성가`).
  무효하면 안내 후 다시 고르게 하고, 취소하면 기존 동작(현재 §3.3.1·§2.1(C)의 취소 규칙)을 따른다.
- **마스터 편의**: 사용자가 'PPT 문서'(세 폴더를 모두 품은 상위 폴더)를 고르면 그 안의 `00.`/`10.`/`20.` 폴더를 자동으로 세 루트로 채우고 다시 묻지 않는다.
- **기존 설정 이관**: 이전 키(`onedrive_ppt_folder` = 옛 'PPT 문서')가 새 구조를 품고 있으면 세 루트를 자동 유도해 저장한다. 옛 구조를 가리키면(현재 이 PC들) 무효로 보고 위 선택창으로 간다.
  옛 `onedrive_hymn_folder`/`onedrive_youth_hymn_folder`는 더 이상 읽지 않는다(루트에서 유도).

### 2.2 변경된 경로 규칙 (`{공용}`·`{성인}`·`{청년}` = 위 세 루트)

| 용도 | 이전 | 변경 후 |
|---|---|---|
| 가톨릭 성가(검색) | `{PPT}/09.가톨릭 성가/성가-악보버전` | `{공용}/09.가톨릭 성가/성가-악보버전` |
| 시작기도·미사후기도 찾아보기 시작 | `{PPT}/13.기도문` | `{공용}/13.기도문` |
| 공지사항 찾아보기 시작 | `{PPT}/11.공지사항 PPT문서` | `{공용}/11.공지사항 PPT문서` |
| 참조 미사 PPT (성인) | `{PPT}/10.기타 PPT문서/PPT 자동화/1.Template` | `{성인}/10.기타 PPT문서/PPT 자동화/1.Template` |
| 화답송 악보 PPT/사진 (성인) | 최초 `{PPT}`, 이후 직전 폴더 | 최초 `{성인}/14.화답송 악보`, 이후 직전 폴더 |
| 참조 미사 PPT (청년) | `{PPT}/20.청년 미사/1.Template` | `{청년}/1.Template` |
| 나주노·야훼이레 성가 검색·**신규 생성 PPT 저장** | `{PPT}/20.청년 미사/2.성가/{나주노 성가\|야훼이레 성가}` | `{청년}/2.성가/{나주노 성가\|야훼이레 성가}` |
| 결과 PPT → 원드라이브로 복사 (성인) | `{PPT}/{YYYY}/` | `{성인}/{YYYY}/` |
| 결과 PPT → 원드라이브로 복사 (청년) | `{PPT}/20.청년 미사/{YYYY}/` | `{청년}/{YYYY}/` |

- 하위 폴더가 없으면 있는 곳까지만 내려가는 기존 규칙은 유지한다(최악엔 해당 루트 자체).
- '원드라이브로 복사'의 연도 폴더 생성·덮어쓰기 확인·오류 안내는 기존 그대로.
- 위 목록 밖에서 옛 경로를 쓰는 곳(원격/Graph 폴백 경로, 운영자 안내서, 배포 빌더의 안내 문구, 테스트)은 구현 단계에서 전수 점검해 함께 바꾼다.

### 2.3 '찾아보기'로 고른 폴더를 기억한다 (향후 구조 변경 대비)
- 첫 입력 화면의 각 파일 행(참조 PPT·시작기도·미사후기도·공지사항·화답송)에서 사용자가 **찾아보기로 다른 폴더의 파일을 고르면, 그 폴더를 행별로 `config.json`에 저장**하고 다음 실행의 그 행 시작 폴더로 쓴다.
  우선순위: ① 저장된 폴더(존재할 때만) → ② §2.2 기본 폴더 → ③ 해당 루트. 저장된 폴더가 사라졌으면 다음 순위로 내려간다(오류 없음).
  참조 PPT 행은 성인/청년을 구분해 저장한다(화답송은 지금의 `last_psalm_dir`을 같은 방식으로 흡수).
- 폴더 선택창(§2.1)에서 사용자가 다른 폴더를 고르면 그 값이 곧 새 루트로 저장되어 다음 실행의 기본값이 된다.
- 폴더 구조가 또 바뀌어 §2.2의 **하위 폴더 이름** 자체가 달라지면 코드 상수(한 곳)를 고쳐 배포한다. 사용자 화면에서 하위 폴더 이름까지 편집하지는 않는다(비목표).

### 2.4 비목표
- 'PPT 문서' 전체를 자동 탐색/동기화하지 않는다. 폴더 이름을 바꾸는 쪽(OneDrive)을 앱이 대신 정리하지 않는다.
- 새 미사 유형(어린이 등) 폴더 지원은 이번 범위 밖(구조만 확장 가능하게 둔다 — 루트 목록에 한 줄 추가).

## 3. 인수 기준
1. 청년 PC(로컬에 `00.공용 PPT`와 `20.청년 미사`가 서로 다른 위치에 있음)에서 청년 실행: 성인 폴더를 묻지 않고, 두 루트만 한 번씩 선택하면 이후 재실행 시 다시 묻지 않는다.
2. 마스터 PC에서 'PPT 문서'를 고르면 세 루트가 한 번에 채워지고 성인·청년 모두 실행된다.
3. §2.2 표의 모든 행이 새 위치로 동작한다(성가 검색, 신규 성가 PPT 저장, 찾아보기 시작 폴더, 결과 복사).
4. 옛 구조를 가리키는 기존 `config.json`으로 실행해도 오류 없이 선택창으로 안내된다.
5. 찾아보기로 다른 폴더를 고르고 재실행하면 그 행이 그 폴더에서 시작하고, 그 폴더를 지우면 기본 폴더로 돌아간다.
6. 기존 회귀 테스트는 새 경로 기준으로 갱신되어 통과한다.

## 4. 확정된 결정 (2026-10-18, 사용자 답변)
1. **OneDrive 로그인(Graph) 폴백 모드는 폐지**한다. 청년 흐름의 Graph 로그인·브라우저·프리페치·다운로드 캐시·원격 조회/업로드와 성인 가톨릭 성가의 Graph 미러링 폴백을 제거하고 로컬 폴더 전용으로 단순화한다. `missa_onedrive.py`와 `msal` 의존도 삭제했다. 폴더 선택이 취소되면 안내 후 종료한다.
2. **'폴더 설정' 화면은 두지 않는다**(옵션 A). 필요한 루트가 없거나 무효할 때만 선택창이 뜬다.
3. 성인 화답송 찾아보기 기본 시작 폴더는 `{성인}/14.화답송 악보`다.
4. 찾아보기 기억은 **행별**이다(참조 PPT는 성인/청년 구분, 화답송은 기존 `last_psalm_dir`을 흡수).
