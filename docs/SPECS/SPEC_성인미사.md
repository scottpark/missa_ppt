# SPEC: 성인미사

> 범위: 성인미사 실행 방식·입력·출력·세부 요구사항 (원문 2부)
> 2026-10-06 새 문서 체계로 이관(원문 `missa_to_ppt 요구사항.md`, 현재는 `archive/legacy-2026-10-06/`). 본문 안의 `§번호`는 그 원문의 절 번호이며 `SPECS/README.md` 매핑표로 찾는다.

## 2.1 실행 방식

### (A) 대화형 모드 — `python missa_to_ppt.py` (또는 `--미사유형 성인`만, 날짜 없이)

팝업 순서: ① 미사 일자 입력 → ② 파일 선택 화면(참조 PPT 필수, 시작기도/공지사항/미사후기도 PPT는
선택 — 화답송 악보 입력 행은 없다(2026-11-17 폐지), 공지사항은 `.pptx`만 허용; 확인 버튼 아래에 현재 버전과 "🔄 업데이트 확인" 링크가
표시된다; '찾아보기' 시작 폴더는 §1.9) → ③ 성가번호 입력(입당·봉헌·성체·2차봉헌·파견 — 주일은 5종 전부, 평일은 2차봉헌
제외 4종 필수, 숫자 형식 검증) → ④ 처리 시작(진행 창, §1.7의 PowerPoint 안내 5초) → ⑤ 결과 창('원드라이브로 복사' 버튼, §1.9).

### (B) CLI 모드 — 날짜 포함 인수 지정

```
python missa_to_ppt.py YYYYMMDD [--입당 N --봉헌 N --성체 N --2차봉헌 N --파견 N]
  [--미사후기도 PATH] [--공지사항 PATH] [--test] [--미사유형 성인]
```

성가번호 생략 시 팝업 입력. `--test`는 팝업 없이 날짜 폴더 파일로 번호를 자동 추론한다(자동화
테스트용). 입력 파일은 `output/YYYYMMDD/`에서 자동 탐색하며 위 옵션으로 경로를 직접 지정할
수 있다. `--공지사항`은 `.pptx`만 허용(다른 확장자는 오류로 중단).

### (C) 성가 폴더 최초 설정

성인미사는 로컬 OneDrive 동기화 폴더의 **공용(`00.공용 PPT`)·성인(`10.성인 미사`) 루트**를 최초 1회 고른다(폴더 구조 개편
2026-10-18, `SPEC_OneDrive_폴더구조_개편.md`). 각 루트는 안에 `09.가톨릭 성가`(공용)/`10.기타 PPT문서`(성인)가 있어야 유효하며, 무효하면 안내 후
다시 묻고 취소하면 안내 후 종료한다(OneDrive 로그인·Graph 미러링 폴백은 폐지). 상위 'PPT 문서'를 고르면 두 루트를 한 번에 채운다. 성가 PPT는
`{공용}/09.가톨릭 성가/성가-악보버전`에서 찾는다. 이 루트로 공통 §1.9의 '찾아보기' 시작 폴더(참조 PPT `{성인}/10.기타 PPT문서/PPT 자동화/1.Template`)와 결과 복사 위치(`{성인}/{YYYY}`)를 정한다.

## 2.2 입력 파일

1. **참조 미사 PPT** — 날짜 폴더 안에서 파일명에 당일 날짜가 없는 `.pptx` 중 선택(성가/
   시작기도 제외). 대화형은 직접 선택(필수), CLI는 자동 탐색.
2. ~~화답송 악보 PPT 또는 사진~~ — **폐지(2026-11-17)**. 주일·평일 모두 화답송은 텍스트로만 표시한다.
   옛 `config.json`의 `화답송_pptx` 키와 날짜 폴더의 `화답송 악보*.pptx`는 조용히 무시한다.
3. **시작기도 PPT** — 선택. 파일명에 "시작기도" 포함 시 자동 탐색.
4. **미사 후 기도 PPT** — 평일미사 전용. 파일명에 "미사후기도" 포함 시 자동 탐색.
5. **공지사항 PPT** — 선택. 지정하면 2차봉헌 성가 콘텐츠 바로 뒤에 원본 서식 그대로 삽입한다.
   2차봉헌 슬롯이 없는 미사는 경고 후 건너뜀. `.pptx`만 허용(확장자 검증).
6. **성가 PPT**(입당·봉헌·성체·2차봉헌·파견) — 주일미사는 OneDrive 로컬 폴더에서 자동 탐색(못 찾으면
   날짜 폴더 폴백) 후 원본 그대로 복사, 평일미사는 악보를 쓰지 않으므로 OneDrive를 조회하지
   않고 구분(divider) 슬라이드 번호만 갱신한다. **필수 악보 파일 검증**: 주일 5종/평일 4종 중
   실제 악보 파일을 못 찾으면 어떤 성가가 없는지 명시한 오류로 중단한다(번호 누락과는 별개로,
   번호는 있으나 파일이 없는 경우를 잡는다).
7. **미사 JSON** — §1.4 공통 규칙.

## 2.3 처리 및 출력

1. `missa_to_json.py` 실행(이미 있으면 생략) → 2. 전례 텍스트 교체(제목·입당송·1독서·2독서·
복음환호송·복음·영성체송) → 3. 시작기도문 교체(지정 시) → 4. 성가 슬라이드 처리(5종) →
5. 검증 → 6. `output/YYYYMMDD/{liturgy}.pptx` 저장. 공지사항은 지정 시 2차봉헌 콘텐츠 뒤에
삽입.

- **주일 추가 처리**: 없음(화답송은 평일과 같은 텍스트 방식, 아래 §화답송).
- **평일 추가 처리**: 파견성가 다음에 미사후기도 삽입(지정 시).

## 2.4 세부 요구사항

**제목 슬라이드**: 날짜(연·월·일)와 전례명(liturgy) 교체, 기존 포맷 유지.

**입당송**: content 앞에 "◎ \t" 추가, 기존 들여쓰기·탭 정렬 유지.

**제1독서**: 제목 슬라이드는 성서명만(절 번호 제거), 본문 슬라이드는 §1.5 공통 규칙.

**화답송**:
- 주일·평일 공통(2026-11-17 통일): 텍스트 슬라이드만. 후렴 ◎와 각 절(`○ 	` + 내용)을 텍스트로
  표시한다. 참조 PPT의 화답송 텍스트 템플릿(악보 없는 구조로 이미 개편됨)을 `find_sections()`로
  동적 탐지해 복제하며, 주일 전용 분기(악보 슬라이드 교대 배치)는 제거한다.
- **서식 원칙(2026-11-18 확정)**: 슬라이드의 ◎ 단락(37pt)·○ 단락(라벨 `○`+탭 30pt, 본문 32pt, 줄간격 1.1)은
  **참조 PPT 템플릿의 단락·run 서식 그대로** 만든다(라벨 run과 본문 run을 구분해 복제). 본문이 슬라이드를 벗어날
  때만 ○ 단락을 줄이며, 순서는 ① ○ 단락 줄간격 1.0 → ② ○ **본문** 글자 크기를 1pt씩 축소(하한 16pt). ◎ 단락의
  크기·줄간격과 ○ 라벨 크기는 건드리지 않는다. 판정은 추정이 아니라 PowerPoint 실측(COM)으로 하며 한계선은
  하단 전례문 줄의 top(슬라이드 높이 이내)이다. 보정 루프의 마지막 실측이 생성 직후 검증을 겸하고, 하한까지 줄여도 넘으면
  경고한다. COM을 쓸 수 없으면 서식을 줄이지 않고 "넘침 미검증" 경고만 낸다.
- 악보 슬라이드 생성 코드(`missa_psalm_score_image.py`의 `render_화답송_score_slide` 등)·
  `assets/화답송_악보_template.pptx`·`tools/build_화답송_template.py`는 **보존**하고 성인미사
  파이프라인에서의 호출만 끊는다(청년미사 성가 PDF 모듈이 같은 모듈의 이미지 유틸 사용).

**제2독서**: 제목은 성서명만, 본문은 §1.5 공통 규칙. JSON이 null이면 슬라이드 전체(직전 blank
포함) 삭제. 평일에도 대축일 등에서 있을 수 있다.

**복음환호송**: 본문 교체, run-level 서식 보존(◎ 알렐루야 줄과 ○ 구절 줄의 서식이 다름).

**복음**: 제목은 복음사가 이름+조사, 본문은 §1.5 공통 규칙.

**영성체송**: 본문 교체.

**성가 처리**(순서: 입당→봉헌→성체→2차봉헌→파견): 주일은 원본 양식 그대로 복사(악보 포함) +
타입/번호 갱신. 원본 악보 첫 줄의 구분 라벨(예: "2차 봉헌")이 이번 주 실제 용도와 다르면 번호와
함께 라벨도 교정한다(찾지 못하면 경고만, 처리는 계속). 라벨/번호 글자 수가 바뀌어도 각 글자의
원본 색상은 유지되어야 한다. 평일은 구분 슬라이드만 갱신, 악보는 복사하지 않고 기존 악보
슬라이드는 삭제한다.

**미사 후 기도**(평일 전용): 파견성가 다음(파견 콘텐츠 → blank → 미사후기도 → blank → 파견
순서 참조)에 원본 서식 그대로 삽입. 파일 미지정 시 생략(오류 아님, 기존 슬라이드가 있으면
보존).

**공지사항 삽입**: `sections['2차봉헌_content_end']`(기존 blank)를 앞 구분선으로 재사용하고,
콘텐츠 뒤에 새 구분 슬라이드 1장만 추가한다. 2차봉헌 슬롯 없음/로드 실패/0장은 경고 후 건너뜀
(예외로 중단하지 않음).
