# SPEC: 청년미사 입력 화면·OneDrive 연동

> 범위: 초기 화면, OneDrive 접속(로컬 폴더 전용), 파일 획득 (원문 §3.2~3.4)
> 2026-10-06 새 문서 체계로 이관(원문 `missa_to_ppt 요구사항.md`, 현재는 `archive/legacy-2026-10-06/`). 본문 안의 `§번호`는 그 원문의 절 번호이며 `SPECS/README.md` 매핑표로 찾는다.

> **2026-10-18 개편**: OneDrive 로그인(Graph) 폴백 모드는 폐지됐다. 접속은 로컬 동기화 폴더 전용이며 폴더 구조·루트 설정은
> `SPEC_OneDrive_폴더구조_개편.md`가 정한다. 이 문서의 §3.3.1·§3.4는 그 결과를 청년미사 관점에서 요약한다.

## 3.2 초기 입력 화면과 미사 유형 분기

- 미사 유형은 `--미사유형` CLI 플래그로 미리 정해지며(§1.1), GUI가 팝업으로 다시 묻지 않는다.
  청년을 선택하면 입력 화면에 성가 출처 4종 선택, 성체성가 2곡 입력, 영문 복음 관련 청년
  전용 옵션만 노출되고(화답송 악보 입력 행은 숨김 — 청년은 화답송 악보를 쓰지 않음), 성인은
  기존 화면 그대로다.
- 확장 가능 구조: `MASS_TYPE_OUTPUT_SUFFIX`/`MASS_TYPES` 류의 매핑에 유형을 추가하는 것만으로
  향후 어린이미사 등을 확장할 수 있게 설계되어 있다(실제 어린이미사 UI 구현은 범위 밖).

## 3.3 OneDrive 연동

- 성당 OneDrive 폴더를 이 PC에 동기화한 **로컬 폴더만** 쓴다. 로그인·네트워크 호출·전용 파일 브라우저는 없다(2026-10-18 폐지;
  `missa_onedrive.py`·`msal` 의존 삭제).
- 청년 운영자는 `00.공용 PPT`와 `20.청년 미사` 두 폴더만 동기화하므로, 설정 단위는 **루트 폴더**(공용·청년)이며 둘은 서로
  다른 위치에 있을 수 있다. 성인 폴더는 묻지 않는다. 설정은 `config.json`에 저장되고(키·이관 규칙은
  `SPEC_OneDrive_폴더구조_개편.md` §2.1), 한 번 정하면 다시 묻지 않는다.

## 3.3.1 청년미사 폴더 루트와 경로 규칙 (2026-10-18 개편)

- 실행 시작 시 필요한 루트(공용·청년)가 없거나 가리키는 폴더가 없으면 폴더 선택창을 띄운다(상위 'PPT 문서'를 고르면 자동으로
  채운다). 선택을 취소하면 안내 후 종료한다(이전의 '로그인 방식으로 진행'은 폐지).
- 모든 단계(파일 선택·성가 조회·결과 복사)가 같은 루트를 공유한다.

| 용도 | 경로 |
|---|---|
| 가톨릭성가 | `{공용}/09.가톨릭 성가/성가-악보버전` |
| 나주노 성가 | `{청년}/2.성가/나주노 성가` |
| 야훼이레 성가 | `{청년}/2.성가/야훼이레 성가` |
| 결과 PPT | `output/`에만 생성한다. `{청년}/{YYYY}/`로의 복사는 결과창 '원드라이브로 복사' 버튼으로만(공통 §1.9, §3.8) |
| 참조 PPT·시작기도·미사후기도·공지사항 | 로컬 파일 선택창, 시작 위치는 공통 §1.9의 행별 폴더(참조 PPT는 `{청년}/1.Template`) |

- 실제 폴더명은 `2.성가`(점 뒤 공백 없음)다.
- 나주노/야훼이레 곡이 폴더에 없으면 PDF에서 새로 생성해 위 청년 성가 폴더에 저장한다 — OneDrive 데스크톱 앱이 동기화하므로 직접
  업로드하지 않는다.
- 참조 PPT·시작기도·미사후기도·공지사항 입력 행의 읽기전용 입력칸·필수/선택 규칙·검증(공지사항은 .pptx만 허용 등)은 성인과 같다.
- 결과 PPT는 `output/{YYYYMMDD}_youth/`에만 생성한다(2026-10-03).

## 3.4 성가 PPT 획득

나주노/야훼이레/가톨릭성가 성가 PPT는 위 로컬 폴더에서 곡 번호 패턴으로 직접 찾는다(곡 하나만 검색, 하위 폴더 포함). 못 찾으면
가톨릭성가는 오류, 나주노/야훼이레는 PDF에서 새로 만들어 저장한다(SPEC_청년_성가.md). 개별 파일(참조 PPT·시작기도·미사후기도·
공지사항)은 사용자가 로컬 파일 선택창으로 고른다.
