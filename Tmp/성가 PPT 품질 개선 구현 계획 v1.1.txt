[사용 라이브러리]

- python-pptx : PPT 읽기/쓰기, 이미지 shape 및 관계(rId) 접근
- Pillow       : 이미지 열기, 업스케일(LANCZOS), Gaussian Blur
- numpy        : Otsu 임계값 계산, morphological 연산
- tkinter      : 파일 선택 팝업 (Python 표준 라이브러리, 별도 설치 불필요)
- argparse     : CLI 인수 파싱 (Python 표준 라이브러리)


[처리 파이프라인]

이미지 1장 기준:

  1. 이미지 열기 (Pillow, 그레이스케일 변환)
  2. 2배 업스케일 (LANCZOS)
       이유: 평균 획 두께 4px → 8px 확보, 이후 처리 정밀도 향상
  3. Gaussian Blur (radius=0.8)
       이유: JPEG 압축 아티팩트 완화 후 이진화 시 경계 노이즈 감소
  4. Otsu 이진화
       이유: 회색 중간값 픽셀 제거, 획을 순수 흑백으로 명확화
  5. Morphological Closing (3×3 커널: dilation → erosion)
       이유: 이진화 후 남은 획 끊김 연결
  6. PNG로 반환
       이유: 흑백 이진 이미지에서 JPEG보다 무손실·고압축


[주요 함수]

otsu_threshold(arr) -> int
  - numpy histogram으로 Otsu 임계값 계산

morphological_op(mask, ksize, dilate) -> ndarray
  - dilate=True: dilation, dilate=False: erosion
  - numpy pad + 슬라이딩 윈도우 구현 (scipy 미사용)

enhance_image(image_bytes) -> bytes
  - 위 파이프라인 전체 실행
  - 입력: 원본 이미지 바이트 / 출력: PNG 바이트

validate_image(original_bytes, enhanced_bytes) -> (bool, str)
  - 아래 4가지 항목 검사 후 (통과 여부, 메시지) 반환
  ① Pillow로 재오픈 가능 여부 (파일 무결성)
  ② 처리 후 어두운 픽셀 비율 < 0.5% → 경고 "이미지가 거의 흰색"
  ③ 처리 후 어두운 픽셀 비율 > 80% → 경고 "이미지가 거의 검정"
  ④ 처리 전후 어두운 픽셀 비율 차이 > 50%p → 경고 "큰 변화 감지"
  - ①번 실패 시 False 반환 (치명적 오류)
  - ②③④는 True 반환하되 경고 메시지 첨부

process_pptx(input_path)
  결과 추적용 딕셔너리 초기화: {success:[], warning:[], failed:[]}
  for 각 슬라이드:
    for 각 PICTURE shape:
      try:
        image_part 추출
        enhanced = enhance_image(image_part.blob)
        ok, msg = validate_image(image_part.blob, enhanced)
        if not ok:
          → failed 목록에 추가, 원본 유지, 다음 shape으로
        if msg:
          → warning 목록에 추가
        image_part._blob = enhanced
        → success 목록에 추가
      except Exception as e:
        → failed 목록에 추가, 오류 원인 기록
  출력 파일명 생성: <원본명>_enhanced.pptx
  ./성가/ 폴더에 저장
  처리 결과 요약 출력

main()
  - argparse로 input 경로 수신
  - 인수 없으면 tkinter.filedialog.askopenfilename() 팝업 표시
      filetypes=[("PowerPoint 파일", "*.pptx")]
      취소(빈 문자열 반환) 시 "파일을 선택하지 않았습니다." 출력 후 종료
  - 파일 존재 여부 및 .pptx 확장자 검사 후 process_pptx() 호출


[PPT 이미지 교체 방식]

python-pptx 내부 구조를 직접 수정:

  pic = shape._pic
  blip = pic.find('.//' + qn('a:blip'))
  rId = blip.get(qn('r:embed'))
  image_part = slide.part.related_parts[rId]
  image_part._blob = enhanced_png_bytes
